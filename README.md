Bargain Beacon — a static Black Friday and Cyber Monday deal finder. 17 real deals, checked 27 Nov 2026, each with its store, store link, sale price, usual price, discount, check time, source, and an honest signal saying whether it is really a deal (new low, strong price, worth a look, or modest cut). Search and filters by category, store and discount all work, sorting by discount, saving or price, and the layout works on desktop and on a phone.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in a browser. No build step, no network requests at run time — every file the page loads lives under `app/`.
